# Forex Academy 📈

A beginner-friendly forex education platform with a risk-free demo trading simulator.

## 🚀 Features
* **Education Hub:** Learn the basics of forex trading, pips, leverage, and risk management.
* **Demo Trading Simulator:** Practice trading major currency pairs (EUR/USD, GBP/USD, etc.) using virtual funds.
* **Portfolio Tracker:** Watch your virtual balance rise and fall in real-time based on market data.

## ⚠️ Disclaimer
**This project is for educational purposes only.** No real-money trading, no financial advice, and no guarantee of results. Demo trades use entirely virtual funds. 

## 🛠️ Tech Stack
* Monorepo: [Turborepo](https://turbo.build/)
* Package Manager: [pnpm](https://pnpm.io/)
* Frontend: Next.js (React), Tailwind CSS
* Backend/API: Next.js API Routes (or Node.js)

## 💻 How to Run Locally
1. Clone the repository: `git clone https://github.com/prabhatbhattarai-dev/forex-academy.git`
2. Install dependencies: `pnpm install`
3. Run the development server: `pnpm dev`
